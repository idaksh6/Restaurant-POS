Mesa POS for Windows
====================

Do not open Mesa POS.exe from inside the zip. Windows then runs a temp copy
and will not keep a desktop icon or Start menu entry.

1. Extract this whole Mesa-POS folder (e.g. to Documents).
2. Double-click "Install Mesa POS.bat".
3. Use the Desktop shortcut, or search Windows for "Mesa POS".

The app is copied to:
  %LOCALAPPDATA%\Programs\Mesa-POS
