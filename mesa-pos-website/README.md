# Restaurant POS Software — Marketing website

Standalone HTML/CSS landing page for restaurant POS software.

## Open locally

1. Open `index.html` in a browser, or
2. From this folder run:

```bash
npx --yes serve .
```

## Files

- `index.html` — page structure and content
- `styles.css` — layout, branding, responsive UI
- `main.js` — mobile nav, scroll reveals, demo form feedback
- `assets/` — hero and feature images
